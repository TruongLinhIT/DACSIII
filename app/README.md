# DACSIII-V2 Android

Auth flow for login/register with OTP and eKYC profile setup.

## Screens
- Login: OTP login + button to Register.
- Register (phone): request OTP.
- Register (OTP): verify OTP.
- Register (profile/eKYC): update profile + upload avatar + upload identity.
